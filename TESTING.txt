The previous few checks were smoke tests, not broad assessment preparation.

WORKFLOW — NO INSTALLATION
1. Write your function in the website editor.
2. Copy public program, paste into Source Academy Python §3, and run.
3. Reason through further boundaries yourself; fix the general algorithm.
4. Copy full program to try all 24 cases without revealing their descriptions.
5. After attempting, enable detailed failures or reveal the additional case
   with the number printed in Source Academy. Hints and solutions remain separate.

SCORING
One case = one point, even if it makes multiple assertions. A case passes only
if all its checks pass. The full run reports public, additional and total cases.
Ordinary failed assertions allow the remaining cases to run. Runtime errors,
nontermination or recursion/resource limits can interrupt the entire run.
The last 'Running case' number identifies the case being attempted. An
interrupted run has no complete score; stop an endless run in Source Academy.
Fixtures and local variables are freshly constructed within each case.

PRIVACY OF TESTS
The additional tests are PRIVATE-STYLE, not truly secret. A static GitHub Pages
site has no secure grading server. The tests exist in the page and copied
program, and you can choose to inspect them. They contain expected results,
not the reference implementation. The site does not run Python itself.

LIMITS
Tests use valid inputs within each exercise's contract. They do not invent
requirements for malformed inputs. Passing finite tests does not prove
correctness, asymptotic complexity, use of the requested algorithm, or absence
of forbidden temporary allocations. Inspect those source-level restrictions.
For example, correct sorted values alone are insufficient for destructive sort:
its cases also check every node in the expected stable identity order.

VALIDATION
All 864 reference cases passed supplemental offline logic checks; the 144
public cases were also checked as a separate copied-program mode. Independent
oracles generated expected graph, sequence and expression values. The suite
detected 37 deliberately faulty implementations across all 36 exercises.
Programs were statically checked against the conservative Python §3 syntax
used in this pack. This is not a claim of official-interpreter execution.
The official Source Academy runtime remains the place to run your attempts.
