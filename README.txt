RUN AN EXERCISE
1. Choose a dojo problem and write your solution in its editor.
2. Click Copy runnable program. This includes needed helpers and checks.
3. Open https://sourceacademy.org/playground and select Python section 3.
4. Paste the entire copied program and run it in Source Academy.
   Successful supplied checks print a message. Review each problem's contract too.

The website itself does not execute Python. It uses the official playground for
execution, so your friends do not need VS Code, a terminal, or a Python installation.
The site's draft storage lasts for the current tab session. Download a draft to keep it.
If copying is blocked, a text box appears for manual copying. Select all and copy it.

PUBLISH WITH THE GITHUB WEBSITE
1. Unzip this package.
2. Create a GitHub repository, for example pa2-practice. Public works with GitHub Free.
3. Use Add file -> Upload files. Upload the extracted contents, not the ZIP.
   index.html must appear at the repository root beside downloads/ and programs/.
   Commit the upload. Include .nojekyll if your file browser shows it.
4. Open Settings -> Pages. Choose Deploy from a branch, your branch (usually main),
   and /(root). Save.
5. When deployment completes, open the link shown there and share it with friends.
   The usual project URL is https://USERNAME.github.io/pa2-practice/.

All internal paths are relative, so project-site subdirectories are supported.
To update, upload changed files and commit them to the same branch.

Official publishing instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
